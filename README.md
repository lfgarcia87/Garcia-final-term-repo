# Garcia-final-term-repo 

Topic: Prepropectus on politics of judicial appointments and interbranch relations.

Explanation: This repository contains the materials for a broader research agenda on the politics of judicial appointments and interbranch bargaining. 
The core project for this semester examines judicial confirmations in the United States, focusing on how the nuclear option changed altered the determinante of the senatorial votes for judicial confirmations, which is part of my qualifying paper. 
The repository will support the project's data collection, analysis, bibliography, manuscript, presentation, and computational outputs. 
It also provides a common baseline for related work that I'm considering to be part of my dissertation prospectus, including a study of delays in Chilean Supreme Court appointments, 
an analysis of presidential selection among candidates shortlisted by the Chilean Supreme Court, and a potential comparative extension examining how institutional differences across appointment systems shape political bargaining and judicial selection.
